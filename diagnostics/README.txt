Mac diagnostic — read-only checks

1. Extract this ZIP.
2. Open Terminal.
3. Type bash followed by a space, drag Check-Mac.command into Terminal, and press Return.
4. Copy the output into the chat.

The script reports macOS, CPU architecture, build tools, and Roblox installation metadata.
It does not request administrator privileges, change security settings, modify files,
attach to Roblox, or test script execution. It does not collect account tokens,
hardware serial numbers, or environment-variable dumps.
